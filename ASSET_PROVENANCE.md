# Asset provenance

The final PNG illustrations in `public/art/` were generated or edited for this project with AI image-generation tools under the project owner's creative direction. The project owner has chosen to distribute these final project assets under the repository's MIT License.

Some final illustrations, including `beauty.png`, were developed with visual references supplied by the project owner. Those source/reference files are not part of the open-source distribution. In particular, `public/art/beauty-source.jpg` is intentionally ignored and must not be committed, packaged, or redistributed.

Before a release, verify the Git staging area and release archive contain only the final assets actually used by the application. Third-party package and vendored-code notices remain governed by their own included license files.
