# 展厅：搜索、私人助手与收藏综述

本次仅修改本地展厅和新增模型接口，不修改原收藏状态、目录或平台数据。

## 使用

- `/gallery` 顶部搜索：覆盖标题、已采集片段、作者、平台、数据库分类和标签；多个关键词用空格分隔，需同时匹配。不搜索回收站，也不会联网读取笔记全文。
- 美妆穿搭的四个二级入口只保留全部收藏。
- 私人助手是独立的全局入口，输入色系、场合、季节与额外偏好，从已保留的美妆穿搭相关收藏生成 2–3 套方案。每套包含发型、美妆护肤、穿搭、美甲；缺少依据时单独标记，不生成适合度百分比。
- 其余七个主题的二级页面增加“收藏综述”，处理该列表中的全部已保留收藏，不受勾选状态影响。

## 数据和模型边界

- 新接口：`POST /api/gallery-insights`，限制为本机同源请求，验证输入、结果结构、引用 ID 和方案四个不同部位。
- 模型调用使用本机现有 `DEEPSEEK_API_KEY`，不向浏览器返回密钥。新功能采用可用模型列表中的 `deepseek-flash`，关闭思考模式。
- 点击生成时才发送标题、分类、片段；不发送 Cookie、图片、媒体或原始链接。
- 范围内每条收藏都传入，标题最多 120 字，片段按总量缩短，结果显示覆盖数量、具备片段数量及截短提示。超过 800 条明确提示拆分，不静默漏项。
- 成功且通过验证的结果保存到本地 settings。缓存按请求条件、收藏 ID、更新时间和目录路径区分；再次以相同条件生成时复用，重新生成可强制更新。
- 摘要仅依据已采集片段，不等于全文研究或视频理解。私人助手允许明确标记的延伸建议，不假装缺失素材存在。

- 浏览器验证：四个美妆入口只有一个标签页；其余七个主题均有收藏综述、不再有灵感推荐。

- 模拟模型返回仅用于验证 UI：两套方案、八个部位、原收藏链接、缺素材提示，以及失败可重试。模拟内容不写入数据库。

接口参数依据：[DeepSeek Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/)。已有分类接口不在本次改动范围。
