# StashMuse

管理 StashMuse 本地收藏整理器。应用只监听 `127.0.0.1`，收藏数据保存在用户电脑；平台同步由用户在已登录的收藏页面主动触发。

## 依赖与安装

- 支持 macOS 或 Linux，需 Node.js 22.13 以上、npm、Chrome、`curl` 与 `unzip`。
- 首次安装前说明：脚本会从 `github.com/geban007-cloud/stashmuse` 下载固定版本，并从 npm 安装锁定依赖；先取得用户确认，再运行 `scripts/bootstrap.sh [安装目录]`。
- `bootstrap.sh` 会校验源码包 SHA-256、构建应用并初始化本地数据库；目标目录只要已经存在就停止，不覆盖或删除已有文件。
- 已有项目时，运行 `scripts/doctor.sh [项目目录]` 做只读检查；缺少依赖时运行 `scripts/install.sh [项目目录]`。
- 使用 `scripts/start.sh [项目目录] [端口]` 启动，默认端口为 `8787`。不要改为局域网或公网监听。

安装过程会访问 GitHub Release 和 npm registry。DeepSeek 与飞书均为可选服务；只有用户自行配置并主动使用对应功能时才会访问。

## 收藏同步

1. 启动应用并打开 `http://127.0.0.1:8787`。
2. 在 Chrome 扩展管理页以“加载已解压的扩展程序”选择项目的 `extension/` 目录。
3. 在本地管理页生成一次性配对码，并填入扩展弹窗。
4. 由用户正常登录平台、打开自己的收藏页，再主动开始同步。
5. 用采集数、导入数、跳过数和本地样本核对结果；没有可观察结果时，不要宣称同步成功。

遇到虚拟列表、分页、登录过期或验证码时，阅读 [平台同步说明](references/platform-sync.md)。验证码和风控必须由用户处理，不得绕过。

## 数据与权限边界

- 不请求、显示、复制或提交 Cookie、验证码、浏览器资料、API Key、Webhook、配对码、本地数据库或导出的个人收藏。
- 扩展只读取用户已经打开的收藏页面，不修改、取消收藏、点赞、删除或自动发布任何平台内容。
- 不下载完整图片、视频或音频；本地只保存元数据、原链接和可选缩略图。
- DeepSeek 分类与飞书推送默认关闭。用户未配置凭据时，手动整理、搜索、备份和浏览必须仍可使用。
- AI 只能提出或执行用户明确要求的整理操作，不得静默覆盖用户确认过的分类。
- 完整数据库恢复、永久清空回收站或其他不可逆操作前，必须再次确认准确目标。
- 不把本地服务暴露到局域网、隧道、云端或公网；当前数据接口没有面向公网的用户认证。

完成操作后说明检查了什么、改变了什么，以及用户还需在登录浏览器中完成什么。
